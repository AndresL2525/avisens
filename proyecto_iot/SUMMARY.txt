✨ CARACTERÍSTICAS PRINCIPALES
═══════════════════════════════════════════════════════════════════════════════

  1. WATCHDOG TIMER (WDT)
     └─ Timeout: 10 segundos
     └─ Detecta deadlocks en tareaGalpon
     └─ Reset automático si no responde

  2. MÁQUINAS DE ESTADO (FSM)
     └─ EstadoSistema: INIT → MONITORING → ERROR → SHUTDOWN
     └─ EstadoPuerta: CERRADA → ABRIENDO → ABIERTA → CERRANDO
     └─ EstadoPersiana: QUIETA → ABRIENDO → PAUSA → CERRANDO
     └─ EstadoAlimentador: APAGADO ↔ ENCENDIDO

  3. FILTRO MEDIA MÓVIL (MovingAverage)
     └─ Buffer circular de 10 muestras
     └─ Aplicado a MQ135 (gases) → Reduce ruido ~80%
     └─ Aplicado a HC-SR04 (nivel agua) → Estabiliza lecturas
     └─ Latencia: ~20ms por filtro

  4. DUAL CORE FreeRTOS
     └─ Core 0: tareaGalpon (sensores/actuadores, prioridad 2, stack 16KB)
     └─ Core 1: tareaWiFi (conectividad, prioridad 1, stack 4KB)
     └─ Desacoplamiento completo

  5. FAIL-SAFE AUTOMÁTICO
     └─ DHT22 falla x3 → Entra en ERROR
     └─ HC-SR04 falla x3 → Entra en ERROR
     └─ failSafe() → Desactiva K1-K3, activa K4 (bomba)
     └─ Protección contra sensores rotos

  6. HISTÉRESIS EN BOMBA
     └─ ON si distancia > 6.0 cm
     └─ OFF si distancia ≤ 3.0 cm
     └─ Evita oscilación continua

  7. WIFI ASÍNCRONO
     └─ Core 1, no bloquea Core 0
     └─ Reconexión automática (30s)
     └─ Preparado para MQTT (v8.0)

🚀 INSTALACIÓN RÁPIDA (3 minutos)
═══════════════════════════════════════════════════════════════════════════════

  1. Instalar PlatformIO:
     $ pip install platformio

  2. Compilar:
     $ pio run -e esp32

  3. Cargar en ESP32:
     $ pio run -e esp32 -t upload

  4. Monitorear:
     $ pio device monitor -e esp32

📊 HARDWARE MAPEADO
═══════════════════════════════════════════════════════════════════════════════

  SENSORES:
    DHT22 ............. GPIO 4
    MQ135 ............. GPIO 34 (ADC)
    KY032 ............. GPIO 33 (pull-up interno)
    HC-SR04 TRIG ...... GPIO 13
    HC-SR04 ECHO ...... GPIO 35

  ACTUADORES:
    Servo puerta ...... GPIO 2  (PWM)
    L293D Canal A:
      EN1 (Persiana) .. GPIO 5  (PWM)
      IN1 ............. GPIO 18
      IN2 ............. GPIO 19
    L293D Canal B:
      EN2 (Alimento) .. GPIO 21 (PWM)
      IN3 ............. GPIO 22
      IN4 ............. GPIO 23

  RELÉS:
    K1 (Calefacción) .. GPIO 32
    K2 (Ventilador) ... GPIO 25
    K3 (Extractor) .... GPIO 27
    K4 (Bomba) ........ GPIO 14
